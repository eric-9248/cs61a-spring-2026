2.5.1 对象和类
类是模板，对象是按模板生成的实例；实例化语法与函数调用相同
实例属性：每个对象独有的名称-值对（如 balance、holder），也称字段/实例变量。
方法：作用于对象的函数，其结果可依赖并改变对象属性；同样参数的两次 withdraw 调用可能返回不同结果。
2.5.2 类的定义
class <name>: <suite> 创建新类；类体中 def 或赋值绑定的名称成为类属性。
构造函数 __init__：首参 self 自动绑定到新创建的对象，用于初始化实例属性。
身份标识：各实例状态独立，用 is / is not 比较标识；赋值绑定名称不创建新对象；只有实例化调用才创建新对象。
方法定义：类体内 def 定义方法，self 绑定调用该方法的对象，从而访问和操作对象状态。
2.5.3 消息传递和点表达式
点表达式 <expression>.<name> 求值为对象的属性；getattr、hasattr 是其函数版等价物。
函数 vs 绑定方法：从类取 Account.deposit 得到普通函数（需显式传 self）；从实例取 spock_account.deposit 得到绑定方法（self 自动绑定）。
命名约定：类名用驼峰（CamelCase）；方法名用小写下划线；以下划线开头的属性表示内部实现细节，不建议用户访问。
2.5.4 类属性
类属性在类体内、方法定义之外赋值，被所有实例共享；修改类属性会影响所有（无同名实例属性的）实例。
点表达式求值规则：先查实例属性 → 再查类属性 → 若是函数则返回绑定方法。实例属性优先，类似本地名称优先于全局名称。
属性赋值：给实例赋值会创建/覆盖同名实例属性，不影响类属性；给类赋值也不影响已存在的同名实例属性。
2.5.5 继承
用基类（父类/超类）与子类表达类的专业化：子类继承父类属性，只重写有差异的部分，未指定的行为自动沿用父类。
继承表达 is-a 关系（支票账户是一种账户）；has-a 关系（银行拥有账户列表）应用实例属性表示，不应继承。
2.5.6 使用继承
语法：class CheckingAccount(Account):，括号中为基类。
类中查找名称：先查本类，查不到沿继承链逐级查父类；对象的类始终不变。
调用父类方法：如 Account.withdraw(self, amount + self.withdraw_charge)；用 self.xxx 而非硬编码类名，便于后续子类覆盖。
接口：不同类共享相同属性名构成接口；使用对象时应只假设接口，不假设具体类型，代码才更健壮。
2.5.7 多继承
Python 支持从多个基类继承，如 AsSeenOnTVAccount(CheckingAccount, SavingsAccount)，兼有提款费、存款费与低利率。
名称冲突时按方法解析顺序（MRO）解决：先左到右、再向上，本例为 AsSeenOnTVAccount → CheckingAccount → SavingsAccount → Account → object；可用 类.mro() 查询，底层是 C3 算法。
2.5.8 对象的作用
对象系统促进关注点分离：每个对象封装一部分程序状态，每个类实现整体逻辑的一部分，抽象屏障划定大型程序的边界。
OOP 适合模拟由独立且相互作用部分构成的系统（社交网络、游戏角色、物理模拟等）。
但类不是万能的：函数式抽象在表达输入-输出关系时往往更自然。Python 是多范式语言，学会判断"何时引入新类、何时用新函数"是重要的软件工程设计技能。
